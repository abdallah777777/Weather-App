# 🌤️ Weather Now

A responsive weather application that provides real-time weather information and forecasts for different cities around the world.

## ✨ Features

- Search for weather by city name.
- Display current weather conditions.
- View daily and hourly forecasts.
- Switch between Celsius and Fahrenheit.
- Dark and Light mode.
- Responsive design for all screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI
